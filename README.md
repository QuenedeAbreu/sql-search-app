💡 Por que o SQL Search PRO?
Muitas vezes, gerenciar centenas de arquivos .sql espalhados em pastas pode ser um caos. O SQL Search PRO nasceu para resolver isso, trazendo a experiência de navegação e edição que você já ama no VS Code, mas focada exclusivamente no fluxo de trabalho com banco de dados.

Seja para encontrar aquela Query complexa perdida em um backup ou para editar scripts rapidamente sem abrir um software pesado, o SQL Search PRO é o seu novo braço direito.

🔥 O que ele faz por você?
🔎 Busca que realmente funciona
Não apenas nomes de arquivos. Busque por conteúdo dentro dos scripts com destaque de palavras-chave e navegação rápida pelos resultados.

🌳 Organização Visual (Explorer)
Navegue por suas pastas e subpastas com uma árvore de diretórios fluida. O sistema monitora seus arquivos em tempo real: se você criar ou deletar um arquivo na pasta, ele atualiza na hora!

🧠 Editor Inteligente
Equipado com o Monaco Editor (o motor por trás do VS Code), você tem:

Highlight de sintaxe SQL completo.

Autocomplete inteligente para palavras-chave.

Suporte nativo a múltiplos encodings (Dê adeus aos caracteres acentuados quebrados em arquivos ANSI/ISO).

💾 Experiência Persistente
Ele lembra de onde você parou. Ao reabrir o app, sua última pasta de trabalho estará lá, pronta para uso.

🛠️ Stack Tecnológica
Construído com o que há de mais moderno no ecossistema Desktop:

Core: Electron & Node.js

Editor: Monaco Editor

File System: Chokidar (Watcher de alta performance)

Encoding: iconv-lite & chardet

🚀 Começando
Instalação rápida
Bash
# Clone o repositório
git clone https://github.com/QuenedeAbreu/sql-search-app.git

# Instale as dependências
npm install

# Inicie o app
npm start
Gerando o executável (.exe)
Para criar uma versão instalável para Windows:

Bash
npm run build
O instalador estará disponível na pasta /dist.
